# 數學家教・家長作業繳交

手機與電腦通用的照片 / PDF 上傳頁，每檔 10 MiB（介面標示 10 MB）。

前台由 GitHub Pages 提供固定入口，嵌入 Google Apps Script 網頁應用程式。家長免登入 Google；程式以部署者身分將檔案寫入指定 Drive 資料夾。Google 存取權杖與可續傳網址留在伺服器。

## 維護

- `admin.html` 是依管理者要求開放的免密碼管理頁，可新增／停用學生，選擇年級、南一／康軒／翰林，以及每週作業／考試截止時間。設定存於 Apps Script Script Properties，附版本檢查避免同時編輯覆蓋。
- `SETTINGS.students` 僅供首次初始名單；管理頁首次儲存後，以雲端設定為準。每位學生使用穩定、不重複的 `id`。
- `apps-script/Index.html` 是完整的響應式介面。
- 檔案直接存入指定 Drive 資料夾；不建立學生子資料夾。檔名由伺服器產生：「年級學期數學_姓名_出版社_類型_小節編號與名稱_上傳裝置_日期時間_序號_收件碼.副檔名」。
- 考試／作業／自訂使用整列膠囊選項；下一整列為對應出版社、年級及學期的章節選單，也可選段考考卷或自訂。
- 每年 7/1 依台北時間升級，2/1 切換下學期。三家出版社六冊目錄見 `docs/curriculum-sources.md`；日後出版社改版需更新資料。
- 手機／電腦以 RWD 自動適應，保留明暗切換；檔名中的實際上傳裝置依瀏覽器訊息判斷。
- 依管理者最新要求，保留上方四張大型翻轉卡，顯示天／小時／分鐘／秒與截止日期；使用伺服器時間校正並支援減少動態偏好。截止後顯示下一個每週截止日，提醒不阻擋逾時上傳。
- 提供後鏡頭拍照入口與相簿／PDF 多選；可補拍、縮圖預覽、逐檔移除。JPEG／PNG／WebP 超過 1.5 MiB 時以 Canvas 縮至長邊最多 1600px、JPEG 品質 0.82，僅採用較小的結果。壓縮後大小依照片內容而異；PDF 不變，HEIC／HEIF 或壓縮失敗保留原檔。原始檔每檔仍須符合 10 MiB 上限。
- 選填附註可收合，完成後顯示經 Drive 確認的收件碼、時間與單元憑證，可再交一份或查看紀錄。
- 以 1 MiB 區塊上傳；進度依 Google Drive 實際確認的位元組更新。失敗重試會先向 Drive 查詢進度，避免重傳已收妥的檔案。重新整理後須重新選檔；未完成的 Google 可續傳連線會自行到期。
- 前後端皆檢查檔案大小、副檔名及檔頭；支援 PDF、JPEG（含 JFIF）、PNG、WebP、HEIC / HEIF，不收影片或 SVG。
- 「作業查看」每 30 秒同步該學生由此版本網站繳交的檔案，提供查看、修改附註、重新上傳及移至垃圾桶。重新上傳使用原 Drive 檔案 ID 更新內容，不新增重複檔案。刪除使用垃圾桶，可由老師復原。
- 檔案操作皆核對固定目的資料夾、此網站標記及學生 ID。前台與後台依管理者要求公開免密碼，姓名選單是分類方式；任何持有網址的人都可操作對應學生的網站紀錄。
- 早期驗收版未加網站標記的檔案，不自動列入新紀錄頁；可直接在 Drive 查看。目的 Drive 原有共用設定不會被程式修改。
- 明暗偏好、上次學生 ID 與學生設定名單快取存於瀏覽器 localStorage；快取只供先顯示，必須取得最新雲端設定才開放選檔。檔案與收件紀錄不永久存於瀏覽器。LINE 等環境若限制儲存，會退回每次重新讀取。
- 前台移除明顯的管理連結，連點左上品牌五次可進後台；這是避免誤觸的入口收納，不是身分驗證。
- 管理頁提供大字基本欄位、分開的作業／考試時間面板、大型文字開關、稱呼即時預覽、教材目錄預覽及固定儲存列。修改有醒目未儲存提示與離頁提醒。未儲存的新卡可移除；現有學生的「移除」會隱藏前台並保留歷史，須儲存才生效。

## 更新與驗收

1. `npm run check`、`node scripts/check-ui.mjs`
2. `clasp -P .clasp.json push`，建立新版本後更新既有部署；保留相同 `/exec` 網址。
3. GitHub Pages 使用 `main` 分支根目錄的 `index.html`。
4. `node scripts/accept-live.mjs`、`node scripts/accept-live.mjs --large` 驗證正式收件服務及 Google 回傳 MD5；`node scripts/check-ui.mjs --live` 用實際前台程式串正式服務驗證預覽、繳交、紀錄、備註、原 ID 重傳與垃圾桶。
5. 檢查正式頁桌面／手機尺寸、明暗模式、翻轉卡、管理設定與跨學期邊界。更動前後端協定時，更新入口 iframe 的版本參數。

Google 配額與 Drive 剩餘空間由部署帳號承擔。首次部署需由帳號持有人授權 Drive 與外部連線。
