# 正式環境驗收

日期：2026-11-13，時區 Asia/Taipei。

- GitHub Pages 前台與管理頁公開網址均可載入；匿名訪客可以取得學生、版本、學期與截止設定。
- 在正式管理頁按下儲存，確認雲端回傳「已儲存」；黃雲晞為國二、南一版，問候稱呼為雲晞，作業／考試每週三 18:00。
- 正式上傳服務收到 PDF、PNG 及自訂分類；直接在指定資料夾的查詢中找到檔案，未建立學生子資料夾。
- 完整 10 MiB PDF 分成 10 個區塊，進度依序從 1,048,576 bytes 到 10,485,760 bytes。Google Drive 回傳 MD5 `158cecf0db27b69faa88124821b78a1a`，與本機檔案一致；收件碼 `CEEDDE7C`。
- 使用實際前台程式在 DOM 測試環境串正式 Google 服務，驗證：PDF 預覽、繳交、自動命名、附註、雲端紀錄、修改附註、同一 Drive 檔案 ID 重新上傳、校驗碼及移至垃圾桶。該流程的測試檔已移至垃圾桶。
- 正式網頁中實際切換作業繳交／作業查看、手機版／電腦版與明暗模式；雲端檔案名稱、附註及管理設定可在畫面核對。截圖保留於本機 `qa/`，未提交公開儲存庫。
- 離線測試涵蓋 10 MiB 上限、空檔／偽裝檔、三家六冊章節、未填自訂內容、台北時區 2/1 與 7/1 邊界、每週截止時刻、設定版本衝突、非目標資料夾檔案拒絕、分塊重試與完成後不重複存檔。

早期測試發現 Drive 檔案回應的位置資訊不足，已改為固定目的資料夾內依收件標記查詢，確認檔案 ID 確實屬於該資料夾與學生後才允許修改／重傳／移至垃圾桶。

重跑方式見 README；正式驗收會新增測試檔案，測試程式只移除該次建立的替換測試檔，不操作家長其他檔案。
